# Publishing guide moved

The publishing guide for this repo now lives **outside** the repo, shared by
every plugin in `C:\GITHUB`:

```
../PUBLISH-GUIDE.md      →   C:\GITHUB\PUBLISH-GUIDE.md
```

It covers the plugin model, scopes/names, install channels, `dist/` builds,
package metadata (`keywords`, `homepage`, `bugs`, `license`, `author`,
`repository`), the pre-publish checklist, and the staging pipeline.

This file is a local pointer only. It is listed in `.gitignore`, is not tracked
by git, and is not published to npm — edit the shared guide, not this stub.
